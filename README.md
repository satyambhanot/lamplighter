# Lamplighter — Team NO Dark Night

A street-light outage dispatch system built for the IEEE YP Industry
Hackathon (Calgary, Oct 2–4, 2026), Case 6.

Full architecture, decisions, and working rules live in
[CLAUDE.md](CLAUDE.md) — treat it as the source of truth.

## Run it

```bash
make setup     # create venv, install requirements
make results   # python -m engine.run_all -> results/
make api       # uvicorn api.main:app --port 8000
make dash      # streamlit run dashboard/app.py
make tunnel    # ngrok http 8000, for the voice agent
make test      # pytest -q
make reset     # restore demo state
```

## Status

Scaffold only — every module under `engine/` and `api/` currently
raises `NotImplementedError` with a docstring describing its contract.
Phases are implemented in order; see CLAUDE.md's "Build order" section.

## Repo layout

```text
config.py     all constants and assumptions
engine/       pure decision logic — no web or database code
api/          FastAPI + SQLite, thin shell over engine/
dashboard/    Streamlit dashboard
voice/        ElevenLabs prompt, tools, setup notes
scripts/      data download, fake-call tester
data/         seed CSV (raw/ gitignored)
results/      charts and CSVs, regenerated by engine/run_all.py
tests/        pytest
docs/         DESIGN.md, DEMO_SCRIPT.md
```
